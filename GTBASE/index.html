Explore Vila Brasa a pé ou de carro. A loja de armas fica perto do ponto de partida.

Como jogar

Toque · Analógico esquerdo para mover. Arraste à direita para girar a câmera. No carro, empurre o analógico para cima para acelerar e para baixo para frear ou dar ré.

PC · WASD ou setas, Shift para correr, E para interagir, R para socar. Mouse para câmera, botão direito ou Q para mirar, botão esquerdo ou F para atirar. Espaço é o freio de mão. Esc pausa.

Xbox · Analógico esquerdo para mover ou dirigir, direito para câmera, A para correr, B para socar, Y para interagir, RT para acelerar ou atirar, LT para frear ou mirar, X para freio de mão e Menu para pausar. Na loja, A confirma e B fecha.
